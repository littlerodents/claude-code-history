# 七牛云/OpenClaw 文章写作规则

> 下次写类似文章时参考这份规则

## 合规红线

### ❌ 绝对不能说

- 七牛云提供 Claude/Gemini/GPT 等海外模型 API 服务
- 七牛云 MaaS 可以调用海外模型
- 通过七牛云访问 Anthropic/Google API

### ✅ 可以说的

- 七牛云 LAS 可以部署 OpenClaw 运行环境（算力服务）
- 七牛云 MaaS 提供国产模型（DeepSeek、Qwen、MiniMax 等）
- OpenClaw 支持用户自行配置各家 API Key
- "第三方开发者视角"进行模型测试

## 文章结构模板

参考硅基流动的 GLM-5 宣传文风格：

```
1. 开篇：时间节点 + 模型定位（制造紧迫感）
2. 权威背书：榜单成绩（量化数据）
3. 技术突破：具体参数变化
4. 基准测试：分数对比表格
5. 实际案例：用 Prompt 生成代码/游戏演示（感性说服）
6. 进阶能力：延伸价值
7. 平台导流：如何体验（合规方式植入）
8. 展望结尾：情怀升华
```

## 模型对比维度

| 对比维度 | 说明 |
|----------|------|
| 功能完整性 | 是否实现所有要求 |
